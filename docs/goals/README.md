# Historical Goal files

The Goal-file workflow is retired. Its 80 task ledgers and short prompts now live in [the history archive](../archive/goals/2026/). Their original bytes and current paths are tracked by the [construction manifest](../archive/migrations/20260908-workspace.json).

These files preserve past requirements, fixed versions, failures and acceptance gates. An old `active` label or an inspection request does not reactivate a task. Current work follows the user's present request and [task routes](../onboarding/current-state.md).

- New implementation records use the [Update entry](../updates/README.md).
- Current API redesign follows its [workflow](../workflows/codex-api-rebuild.md).
- History handling and current ownership follow [document governance](../workflows/document-governance.md).

The [0.3.1 handoff](../archive/goals/2026/20260606-0001-031-regression-new-content.md) and [original prompt](../archive/goals/2026/20260606-0001-031-regression-new-content.goal.txt) retain the user-corrected automatic version-bump mistake. They do not determine any future version.
