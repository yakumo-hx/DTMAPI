# Y 键控制台世界动作优化路线

Date: 2026-08-01

## Current boundary

DTMAPI 0.5.5 暂时不在玩家界面构建“发电机”“怪物”“资源”三个入口，也不显示它们旁边的原生 owner/白名单状态说明。此次改动仅收起尚未形成完整玩家语义的 UI；ProductNative 动作执行器、翻译键、冻结 ABI、Compatibility Host 路径和生命周期清理继续保留。

这不是功能删除或卸载承诺。旧兼容消费者仍可调用既有执行路径，其 Harmony、世界修改、存档副作用和失败结果继续受各自既有契约约束。

## Reopen requirements

### 怪物与资源

重新开放前必须同时完成：

- 可搜索、可分页的具体对象选择；
- 明确数量，不再默认选择“第一个”；
- 当前场景可用性和不可用原因；
- 生成位置、影响范围和世界 owner；
- 执行前二次确认；
- 执行后的实际结果验证与明确失败反馈。

### 发电机

先确认内容 owner、当前存档是否真正可用以及给予后的可观察结果。优先评估把它并入现有物品浏览器，通过统一的搜索、数量、背包容量预检和给予结果界面提供，而不是保留一个语义孤立的高级按钮。

## Required review before implementation

三项中的任何一项重新进入玩家 UI 前，都要重新审查：

- 世界状态修改由谁拥有，是否会与原生或第三方 owner 冲突；
- 所有预检是否在状态修改前完成；
- 部分成功、异常和结果不可验证时的失败传播与回滚；
- 返回标题、不保存退出、正常原生保存、保存失败和冷重载语义；
- Compatibility 调用与新玩家 UI 是否会形成双 owner 或重复执行。

完成上述设计、聚焦 Unit 和隔离存档验收前，这三个入口保持隐藏。后续实现不得借此把产品逻辑移入 Manager 或扩大平台 Runtime。
