## 事件图中的等级、天数和醒来不可混为一个门

内在好感每 100 值一等级，UI 每两等级一颗心，上限内部 10 即五颗完整心。DAY_PASSED 是跨日，WAKE_UP 是另一事件。该基线奖励条件为：

| 奖励/事件 | 图记录的触发与等待 |
| --- | --- |
| 克劳德“多出来的种植盆” | 内部等级 2（一心）后跨一天；不是半心 |
| 后续镇政厅故事 | 内部等级 3（一心半），入镇政厅且小时 6–17（至 17:59） |
| 萨科“回执邮件” | 内部等级 2 后下一次醒来；不是半心 |
| 备用电源 | 飞廉内部等级 10，入种子店触发故事，再跨三天；无附加醒来 listener |
| 列车长的怀表 | 前置克劳德镇政厅事件与满好感后跨两天 |
| 推进装置散热器 | “飞向宇宙”完成后跨三天，再接醒来；正常睡眠顺序是第三次跨日后的醒来，不多等第四天 |
| 战车呼叫器 | 泽尼瑟满好感故事后跨一天 |
| 小雕像 | 奥兰多满好感故事后跨两天 |

节点和 email ID 的确切定位保留在原 Review。不能只查最终邮件表就断言取得条件，须跟踪图连接、计数和额外条件。

## 常青说明先核实事实，再移除旧版本标签

同一基线的里科山“极限利用”要求 20 薄荷油，故“无用途”不成立。风力/太阳能被配置为户外设备；电力控制室对覆盖或相邻格检查到的户外发电机可提供 40% 加成，取匹配建筑效果最大值。旧室内放置 bug 指针需标成历史，不能当现行规则。

“当前版本 0.94/0.95”的条目应重新核实事实后去掉旧标签；真正的历史截止表述留在历史语境，版本史本来包含这些词，不批量删除。该次调查只读 Wiki 并追踪 native 图/配置，没有保存网页，也无需游戏测试；后续编辑归 Wiki 内容任务。
