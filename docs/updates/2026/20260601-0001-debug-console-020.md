## Known Facts And Rejected Hypotheses

- Known: `DTMAPI.DebugConsoleMod` is installed under the game's ordinary `Mods/DTMAPI.DebugConsoleMod` path only when requested by smoke/dev install; it is not an extra BepInEx plugin.
- Known: the console must stay closed before `SaveLoaded`; retained smoke `GAME-SMOKE/20260601-055310` logged a pre-save `T` as ignored by the mod.
- Known: item debug smoke should prefer common item IDs. The final smoke gives `wood` through native backpack placement and records before/after counts.
- Known: current weather switching can be requested through native `ArchiveDataHandle.SetWeather` and `PatchWeather`; current-period patching remains experimental.
- Known: teleport smoke used the native mark-point transport path and verified a room/position change after the request.
- Rejected: putting the debug console ordinary mod into `BepInEx/plugins`.
- Rejected: directly editing save files, player coordinates, inventory arrays, or raw public API types for these debug actions.
- Rejected: treating earlier failed debug-console smokes as API failures. `GAME-SMOKE/20260601-054331` and `GAME-SMOKE/20260601-054917` verified Items/Weather/Teleport while the external key harness needed foreground/key-state hardening; `GAME-SMOKE/20260601-055310` verified the actual T/Escape/T/T behavior but failed on an overly strict expected close reason.

## Implementation

- Bumped runtime/package version to 0.2.0.
- Added experimental public APIs and DTOs:
  - `IDebugConsoleApi`
  - `IInventoryDebugApi`
  - `IWeatherDebugApi`
  - `ITeleportDebugApi`
- Added `ReflectedDebugConsoleUi`, a reflected Unity Canvas host with Chinese-first labels and English fallback.
- Added ordinary `testmods/DebugConsoleMod`:
  - registers `T` and `Escape`,
  - only toggles after `SaveLoaded`,
  - closes on `ReturnedToTitle`,
  - binds the host to inventory/weather/teleport APIs.
- Added GameBridge debug API implementations:
  - inventory enumerates `DolocConfig.Tables.TbItem`, validates through `QueryItemProto`, checks native backpack capacity, then calls `TryPlaceInBackpack`;
  - weather reads current date/season/weather and `GetWeatherInfoOfDay(0)`, lists `TbWeather`, and switches through `SetWeather` plus optional `PatchWeather`;
  - teleport builds a whitelist from init farm mark point, station table, and key mark-point keywords, then calls `DolocAPI.DoTransport`.
- Added smoke automation:
  - `run-game-smoke.ps1` can install DebugConsoleMod, send foreground-verified T/Escape/T/T, and assert log counts;
  - GameBridge smoke can exercise debug inventory/weather/teleport APIs after third-save load and auto-exit after evidence capture.
- Icon status: the inventory API exposes `HasIcon` and `IconAssetKey` metadata from item protos. The first Canvas menu keeps icon rendering text-only because reflecting raw Unity Sprite/Image assets safely needs another pass and should not leak raw game types into the public API.
