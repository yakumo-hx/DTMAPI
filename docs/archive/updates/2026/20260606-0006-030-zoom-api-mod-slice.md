## Implementation Notes

- Added experimental `ICameraZoomApi` with typed options, result, state, and status DTOs. The API exposes view-scale numbers and status only; it does not expose Unity camera objects or decompiled game types.
- Implemented GameBridge camera zoom through reflected `DolocAPI.mainCamera.orthographicSize` with `UnityEngine.Camera.main` fallback.
- Added save/title lifecycle reset so zoom returns to vanilla on `SaveLoaded` and `ReturnedToTitle`.
- Added `ZoomMod` as an ordinary official-local DTMAPI mod under `MODS/DTMAPI_Zoom`, not under `BepInEx/plugins`.
- Added `Equals`/`Plus`, `Minus`, `KeypadPlus`, and `KeypadMinus` input names so keyboard `+` / `-` can drive the mod.
- Added `-AutoExerciseZoom` smoke support and a Zoom-specific direct-load fallback when the title UI state is not observed before the smoke timeout.
- Changed CameraZoom `GetState` to return a snapshot copy, preventing callers from mutating or observing later in-place internal state changes.
