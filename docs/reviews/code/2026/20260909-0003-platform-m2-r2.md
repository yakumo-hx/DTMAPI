## 输入与核验

[集中实机证据](../../../debug/evidence/GAME-SMOKE/20260909-platform-pn020-runtime/README.md)绑定候选 G、与 D 相同的 SDK ZIP、两位仓库外作者和普通旧 SDK 产物。沿 [PN-005](../../../updates/2026/20260909-0002-platform-optional-services.md)、[PN-009](../../../updates/2026/20260909-0004-platform-context-scheduler.md)、[PN-018](../../../updates/2026/20260909-0003-platform-owner-global-data.md)、[PN-019](../../../updates/2026/20260909-0005-platform-config-input-i18n.md)复用未变的 Core/SDK 故障测试，核查服务目录、平台队列/命令/owner 关闭、输入诊断、翻译订阅与 Bootstrap 退出变更。没有重做全平台原生审计。

两个独立作者从正常候选 SDK 编译、打包、安装并在 Mono 调用新服务。原 retained helper 与 consumer 两 DLL 以原始 hash 加载、实例化和 Entry 调用，结果 73/一次写入；新可选服务缺失分支如约。可选服务采用固定 Type 和 owner activation，不修改旧 IDtmHelper/Entry 抽象槽；旧冻结 0.5.5 载荷不重写。

实际路径涵盖后台→主线程、下个 tick、取消/期限/队列容量、异常后存活、两个完整读档循环、房间变化、真实新游戏、IO 失败后同进程恢复、标题命令和认证命令、配置迁移失败保全、全局数据冷启动保留、语言可见刷新，以及暂停时按住键到恢复后的 neutral rearm。新游戏在序章期间保持 LoadingWorld；IO false 清空失败 epoch，重试分配新 epoch。WorldReady 使用新成功加载、AfterLoad、房间进入/当前房间一致及原生 normal frame 的组合，未增加帧驱动。

退出缺口按 [有界 Review](20260909-0002-platform-shutdown-entry.md)修复。原生退出按钮与 QA Application.Quit 两条路径均出现一次 Application.quitting 主线程关闭、ShuttingDown、Mod Dispose、逆序资源释放和 remaining=0/failures=0。实机失败记录保留；不从“进程已退出”倒推清理成功。最后一轮 runner 20260909-105136 Passed，三包公开 withdraw、五 DLL 精确还原、真实 30 个存档文件/5 个 sidecar 的 hash/长度/时间与数量不变，启用基线不变，锁已释放。

## 接受的公共语义与限制

- Runtime snapshot 可后台读取；服务取得、订阅/资源/配置/文件操作按各契约的 Runtime 线程约束。Scheduler 的同步 Action 不 inline；Completion 不承诺主线程。取消只作用于未开始工作，慢回调无法抢占。容量/预算是有界实现，不是实时保证。
- SaveSession/World epoch 是进程内寿命，不是原生保存身份。失败先失效，无新成功事实保持不可用；不保证修复原生缺失/损坏档的同进程恢复。上下文 ready 也不表示每个可选玩法功能可用。
- Config/global data 有 owner、schema、摘要和一次原子发布；损坏/未来格式不以默认值覆盖。它们不属于原生保存事务，没有 SaveData、Steam Cloud 或进程断电持久性保证。
- 输入诊断复用既有 audience/scope/neutral 数据。真实键盘和暂停恢复已有证明；本机无连接手柄，控制器实按未测。作者页面的可见证明限标题界面；标题输入框不能单独证明 Gameplay 的 typing-focus 因果。
- 命令各前端共用调度器，作者会话验证 request/owner/source；输出有界。现有初次 ReturnHome 对已使用会话的关闭规则保留，作者按实际会话寿命使用。
- 本次长期新游戏对话使十分钟 save-scope 探针自然执行；日志中的 ERROR 字样不是跨失效 epoch 的证明，已在证据说明。取消结论来自短循环和真实失败/返回边界。
- 接受的 target 只含已经实现的可选服务、context/调度/资源/命令、owner 文件/全局数据、配置/输入诊断/翻译。Reflection、依赖 DLL/原生声明新格式、SaveData 和持久实体均不回填本 target。

## PN-007.b 出口

冻结相同候选 contract、Abstractions 字节和可复现自有源码配方；旧 payload/contract 保持原 hash。普通构建脚本须按 catalog 准备两套 payload，新模板选择 0.7.0，旧项目继续选择旧 target；重新执行受影响的 SDK 组合/确定性/损坏拒绝检查。任何契约或运行行为修订都会撤销对应证据复用，需要最小相关重验；单纯冻结/打包不要求再跑已通过且 DLL 未变的游戏场景。
