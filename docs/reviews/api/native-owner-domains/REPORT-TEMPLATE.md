## API Translation Notes

- Stable contracts should use DTMAPI-owned DTOs, result objects, opaque IDs, and adapter services.
- Public APIs must not expose raw decompiled game types, Unity objects, Harmony patch state, or mutable native singletons.
- State mutation requires owner-token, restore, save/load, transition, disable/re-enable, and multi-mod conflict policy before ordinary-mod use.
