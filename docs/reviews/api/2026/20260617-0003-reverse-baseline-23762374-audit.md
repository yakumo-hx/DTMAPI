## Decision

Use `23762374_public_C416D4` as the current local reverse reference for new design, hook research, and worktree handoff.

Do not rewrite the historical per-domain report headers from `23465763_workshop_38581E`. Those reports were authored on the older build. Future API rebuild work should start from the domain report, then re-open the named symbols and method bodies in the current reference build before implementation.
