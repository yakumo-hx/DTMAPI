# Tests

Test projects should live here:

- `DTMAPI.UnitTests`: pure manifest, dependency, config, logging, registry, and utility tests.
- `DTMAPI.IntegrationTests`: file layout, loader, compatibility database, and report packaging tests.

Game-process orchestration belongs in `tools/scripts`. Optional QA Mod packages
and negative loader fixtures belong under `tests/mod-fixtures`; reusable author
examples and API-demand samples belong under `author-sdk/examples` and
`author-sdk/samples`.
