DTMAPI 0 号存档一键恢复（玩家专用）

这个 ZIP 只适用于收到它的这位玩家，不要转发给其他玩家。
包内含一份已验证且仍为游戏原生加密格式的恢复源。

使用方法：

1. 完全退出 Doloc Town。
2. 在 Steam 托盘图标上选择“退出”，确认 Steam 整个客户端也已关闭。
3. 把 ZIP 完整解压到一个普通文件夹，不要直接在压缩包预览中运行。
4. 双击 1_restore_verified_slot0.bat。
5. 看到 [OK] 后，重新启动 Steam 和游戏，打开存档列表并加载 0 号档。

脚本只做一件事：

- 把已验证的原生加密恢复源替换为 doloc-save-0.data。恢复源可以是原生备份，也可以是经严格校验的定点修复档。

安全边界：

- 不会在玩家电脑创建新的存档备份；维护者已经保存了完整原始包。
- 不会删除、移动或覆盖现有 .prev0、.prev1、.prev2、.prev3、.prev4。
- 不会修改其他存档、flags.json、mod_infos.json 或 steam_autocloud.vdf。
- 只有当前坏档和恢复来源都与本次采集的 SHA-256 完全一致时才会替换。
- 如果玩家在采集后又保存过、Steam 云已改写文件，或者文件不匹配，脚本会拒绝执行。
- 恢复使用同目录原子替换；游戏或 Steam 仍在运行时会拒绝执行。

恢复后注意：

- 如果 Steam 显示云存档冲突，选择本机上时间更新的文件。
- 在修复版发布前，不要再使用 DTMAPI DebugConsole 的原生保存按钮。
- 进入游戏并确认房间正常显示后，后续请使用游戏本身的正常保存流程。
- 如果没有看到 [OK]，不要手动删除任何 SAVE 文件；把窗口内容截图发给维护者。

隐私提醒：这个 ZIP 含玩家存档，只应由该玩家本人和可信维护者保管。
