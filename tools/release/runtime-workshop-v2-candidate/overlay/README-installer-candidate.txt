DTMAPI Runtime installer V2 candidate

1_install_dtmapi.bat
  Install or repair the bundled BepInEx files and DTMAPI Runtime.

2_uninstall_dtmapi.bat
  Remove DTMAPI Runtime. Keep BepInEx, BepInEx settings and DTMAPI logs.

3_check_dtmapi_status.bat
  Read-only lightweight status check.

4_collect_dtmapi_logs.bat
  Export the newest ten complete DTMAPI logs. Close the game first.

9_full_uninstall_dtmapi_and_bepinex.bat
  After explicit confirmation, remove DTMAPI, all BepInEx DLL mods/settings,
  Doorstop files and residual DTMAPI/BepInEx logs. It does not remove saves,
  Workshop subscriptions, Unity Player.log or unrelated game files.

If an installer path is not supported, copy the whole DTMAPI folder to a path
containing only English letters and numbers, then try again.
