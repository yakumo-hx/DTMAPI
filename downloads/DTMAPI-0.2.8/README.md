# DTMAPI-0.2.8 Package Notes

This folder is the useful download payload for the current public preview.

- Runtime goes under Doloc Town/BepInEx/plugins/DTMAPI.
- Official local mods go under Doloc Town's local MODS folder.
- BepInEx itself is not bundled.
- This package does not include unfinished experimental mods such as Y console, Mine, More Equipment Slots, Second Motor, AutoFishing, Animal Husbandry Progress, Oil, or Fish Breeding Assistant.
