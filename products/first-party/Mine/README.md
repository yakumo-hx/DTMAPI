# DTMAPI Mine

Mine is a first-party Advanced CodeMod with split ownership:

- official JSON owns `dtmapi_mine`, its 16-slot native `Case`, workbench
  recipe and content identity;
- ProductNative owns session-derived production, weighted output selection,
  optional Oil recipe/tech mutation and Mine-only 2x visual lifecycle;
- native `ElectronicComponentAppliance.Launch()` consumes the fixed JSON
  threshold `10`;
- native save data owns only the case inventory and electric charge.

The scheduler intentionally has no sidecar. Each `SaveLoaded` starts newly
observed Mines at `current TotalTUs + cycle`; title, disable and owner unload
clear every due entry. Exact cross-exit cycle continuity is not promised.
Cold `Enabled=false` registers no native hooks. Turning it on later is
restart-required so the exact hook set remains part of supervised `Entry`;
turning it off restores the product-owned native state immediately.

The frozen `IMachineProductionApi` is not used or provided by this product.
