# DTMAPI Fish Roe Info Display

This is the separately admitted fourth first-party Advanced CodeMod. It is optional and is not part of the five-assembly DTMAPI Runtime.

The product owns one `Item.get_title` Harmony Postfix, fish-roe title formatting, duplicate-marker protection, lifecycle state and exact-owner cleanup. It consumes the narrow Experimental `IItemDisplayNameApi` only for the shared read-only `itemId -> localized display name` native lookup. It does not consume `IItemTooltipApi`; that API remains a frozen, demand-inactive compatibility boundary for older compiled Strict consumers during the 0.5.5 window.

The former generated lookup was an empty public placeholder and is not a production data source. A future clean-room incubation/growth dataset belongs to a separately admitted ContentOwner/G7 boundary.

Player identity remains `Yuuka.DTMAPI.FishBreedingAssistant`; the next package is projected as version `1.0.0` on Workshop item `3742763706`, with the existing config keys/defaults and title-only behavior.
