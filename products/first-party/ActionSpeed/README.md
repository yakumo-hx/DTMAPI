# ActionSpeed

Managed Advanced ProductNative implementation of `Yuuka.DTMAPI.ActionSpeed`.

- preserves Workshop item `3742763309`, projects the next package as version `1.0.0`, and keeps the canonical config path and F10 configuration entry;
- installs one exact-owner eleven-Hook inventory atomically, including the independent manual-watering state;
- restores product-held animator and animal-interaction state on action exit, save load, title return, failure, disable/configuration change, and owner deactivation;
- does not consume the frozen GameBridge `IActionSpeedApi` compatibility surface;
- builds and packages only through the DTMAPI Author SDK and Catalog-driven Advanced product builder.

The old experimental ABI remains in mandatory GameBridge solely for retained Strict binaries during the `0.5.5` compatibility window.
