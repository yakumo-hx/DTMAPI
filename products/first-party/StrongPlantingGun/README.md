# DTMAPI Strong Planting Gun

This Advanced ProductNative mod owns the fixed three-slot policy for the
official farming gun. The three supported categories are seed, film, and
fertilizer. Water, range expansion, general farming automation, and a public
container API are intentionally outside this product.

The game remains the owner of each gun's serialized `LinearInventory` and of
all planting checks. On disable, title return, or owner deactivation the mod
restores the exact observed native function capacity without shrinking or
rewriting any gun inventory.
