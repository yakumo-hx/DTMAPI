# First-party product sources

This root contains DTMAPI-owned product source, including published products and bounded prototypes.
Physical placement here does not grant release eligibility or Advanced CodeMod admission.
`tools/release/dtmapi-product-catalog.json` remains authoritative for each product's role, identity,
distribution state, package lane, and release gate.

Product-specific gameplay policy stays with its product. Platform Runtime projects must not absorb
that policy merely because the source is first-party.
