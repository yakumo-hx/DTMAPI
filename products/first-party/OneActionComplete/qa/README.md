# OneActionComplete QA boundary

OneActionComplete does not ship resident QA counters, reflection observers or diagnostic state. The product is stateless across its two Postfix callbacks apart from configuration and duplicate-log suppression, so its focused admission gate is `tools/scripts/test-batch6-oneactioncomplete-advanced-product.ps1` plus the tracked Author SDK validate/build/pack flow.

A later runtime acceptance may observe native resource, energy, fuel and feeder effects and the product log from outside the player package. It must not add a product API or shared QA ABI merely to expose those observations.
