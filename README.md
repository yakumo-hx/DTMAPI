# DTMAPI Public Preview

DTMAPI is an experimental Doloc Town Modding API built on BepInEx. This public branch is a curated preview/download snapshot, not the full local research workspace.

## Included

- downloads/DTMAPI-0.2.8/BepInEx/plugins/DTMAPI: DTMAPI runtime DLLs.
- downloads/DTMAPI-0.2.8/OfficialLocalMods/Yuuka_DTMAPI_ActionSpeed: confirmed Action Speed DTMAPI package.
- downloads/DTMAPI-0.2.8/OfficialLocalMods/Yuuka_DTMAPI_OneActionComplete: confirmed One Action Complete DTMAPI package.
- docs/public-api-matrix.md: current public/experimental API status.
- ssets/branding: DTMAPI icon and preview assets.

## Not Included

This branch intentionally does not publish the full source tree, reverse-engineering references, official decompiled files, third-party mod samples, local debug evidence, or unfinished/unsafe experimental mods.

## Install Sketch

1. Install BepInEx for Doloc Town once.
2. Copy downloads/DTMAPI-0.2.8/BepInEx/plugins/DTMAPI into the game's BepInEx/plugins/DTMAPI folder.
3. Copy confirmed packages from downloads/DTMAPI-0.2.8/OfficialLocalMods into Doloc Town's official local MODS folder.
4. Start Doloc Town normally through Steam and enable/configure the local mods through the official Mod UI plus DTMAPI settings.

Status: DTMAPI 0.2.8 public preview. Action Speed and One Action Complete were selected because the user marked them as currently confirmed.
