# Legacy product assets

This root preserves non-buildable artwork, localization, and metadata left by retired legacy
product trees. These files are audit/reference material only:

- they are not active product source;
- they are not Author SDK examples or QA fixtures;
- they must not be scanned, built, installed, or packaged as player Runtime or current Mods.

Current identity, distribution, and release facts remain in
`tools/release/dtmapi-product-catalog.json`.
