一、整体说明

•在02 新增鱼、03 新增料理（自由烹饪料理）的基础上新增：

◦养殖鱼-道具信息item_tbitem.json、

◦养殖鱼-孵化fishing_tbfarmfish.json

◦养殖鱼-杂交阵型与产出fishing_tbfarmfishformation.json、item_tbitemspawn.json

◦烘干机配方recipe_tbrecipe.json、mod_tbmodrecipegroupextension.json

◦加入食材组mod_tbmodingredientgroupextension.json

◦鱼图鉴fishing_tbfishdocument.json

•配置示例中，标黄的字段为【需要修改的字段】。

9.fishing_tbfarmfishformation.json

•养殖鱼的杂交阵型：3条或以上鲮鱼（fish0），能产出掉落库fish1。

[
  {
    "id": "fish1", //阵型ID，同养殖鱼OD
    "weight": 6,  //阵型权重
    "formation_output_fish": "fish1", //道具生成表ID
    "count_range": {
      "x": 1, //产出最小数量
      "y": 1 //产出最大数量
    },
    //以下为需要满足的阵型要求
    "formation_conditions": [
      {
        "fish_id": "fish0",   //鱼ID
        "count_range": {
          "x": 3, //最小要求数量（闭区间，-1为无限制）
          "y": -1 //最大要求数量（闭区间，-1为无限制）
        },
        "index": -1 //填-1，不动
      }
    ]
  }
]

11.recipe_tbrecipe.json

•新增烘干机配方：

◦2*鱼干（dried_fish_small） =  1*鲮鱼（fish0）

◦4*鱼干（dried_fish_small） =  1*蓝色鲮鱼（fish1）

[
//以下为鲮鱼的烘干配方
  {
    "id": "dried_fish_fish0", //配方ID，一般等同道具ID
    "default_unlock": false, //是否默认解锁
    "title": {
      "key": "", //配方标题（为空则根据输出道具自动生成）
      "text": "" //配方文本（为空则根据输出道具自动生成）
    },
    "cost_time": 288, //制作时间（单位为TU，即游戏内5min）
    "output_item": {
      "item_name": "dried_fish_small", //输出道具的道具ID
      "min_count": 2, //最小输出数量
      "max_count": 2 //最大输出数量
    },
    "input_items": [
      {
        "item_name": "fish0", //消耗道具的道具ID
        "item_count": 1 //消耗道具数量
    ],
    "recipe_sub_type": "cook", //配方小类
    "tech_point": 5, //完成配方增加的科技点数
    "show_in_handbook": true //配方是否显示在图鉴
  },
  //以下为蓝色鲮鱼的烘干配方
    {
    "id": "dried_fish_fish1", //配方ID，一般等同道具ID
    "default_unlock": false, //是否默认解锁
    "title": {
      "key": "", //配方标题（为空则根据输出道具自动生成）
      "text": "" //配方文本（为空则根据输出道具自动生成）
    },
    "cost_time": 288, //制作时间（单位为TU，即游戏内5min）
    "output_item": {
      "item_name": "dried_fish_small", //输出道具的道具ID
      "min_count": 4, //最小输出数量
      "max_count": 4 //最大输出数量

    "input_items": [
