# DTMAPI 自动钓鱼

`Yuuka.DTMAPI.AutoFishing` 1.1.0 候选，面向 Runtime 0.7.0。持鱼竿站在真实水域旁，默认用 F6 开启／停止；在标题页 DTMAPI 设置中改键与配置。

默认循环使用原生抛竿、等待、钓鱼小游戏和结算。绿条保持输入，黄色音符点击一次，红条松开。原生移动、跳跃和其他中断会结束自动循环。

| 选项 | 默认值与范围 |
| --- | --- |
| 立即咬钩 | 关闭；开启后缩短等待，仍使用原生鱼种和鱼竿资格 |
| 跳过小游戏 | 关闭；单独决定小游戏处理 |
| 钓鱼动画加速 | 关闭；开启时只改变本次钓鱼的角色、鱼竿、帽子和钩子运动 |
| 抛竿蓄力幅度 | 0；可选 0～1，仍完成原生准备动画 |
| 动画倍率 | 3；支持 1～5，旧配置超过 5 时收窄到 5 |

选项互不隐含开启。产品不改变全局时钟，不自行结算鱼获，不写入原生存档或玩法 sidecar。旧 `VerboseLogging` 配置不再使用。

## 构建与清理

源码为 `src/`，程序集保持 `netstandard2.0`。使用普通 .NET 工程和显式本机 API／原生引用构建；原生依赖不进入产品包。Harmony Owner 为 `Yuuka.DTMAPI.AutoFishing.Native`。

停止、返回标题和 Dispose 分别释放输入、运动状态与补丁。Owner 已失活时不再访问事件 helper；各项清理独立尝试，失败项保留重试责任。失败的重力设置不会把尚未加速的速度除以倍率。

聚焦测试：`build/test-unit.ps1 -Focus autofishing-product`。短探针是单独的测试 Mod，使用第 5 槽（native index 4）真实池塘，需先通过 NoNativeSave／回收预检并持有 Runtime lock。
