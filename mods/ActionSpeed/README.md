# DTMAPI动作加速

`Yuuka.DTMAPI.ActionSpeed` 2.0.0，面向 DTMAPI Runtime 0.7.0。通过官方 Mod 列表启用或停用；通过 DTMAPI 本体的模组配置入口打开“DTMAPI动作加速”。

| 配置 | 动作 |
| --- | --- |
| 工具加速 | 斧、镐、镰刀，水壶手动浇水 |
| 装水加速 | 空瓶装水、水壶补水，包括合法水容器 |
| 吃喝加速 | 食物和饮水动画 |
| 交互加速 | 加燃料、加饲料、抚摸动物、取奶、电器交互 |
| 采集加速 | 作物收获、可采集物、树脂 |
| 种植加速 | 播种、种树、施肥、保护膜及种植枪 |

六类动作各自启用、各自设置 1～4 倍速度，默认均为 3。原生动作资格、体力、物品消耗和结果保持由游戏处理。

自动装水默认关闭：在水中选中空瓶后自动尝试原生装水动作，普通间隔 0.25 秒，强力间隔 0.12 秒。正在做动作时等待，动画快慢由“装水加速”单独决定。

“右键持续喝水”默认开启，仅在持续饮用瓶装水时，让原生连续使用计时以 3 倍推进。普通食物仍使用原生分段节奏，吃喝动画开关不影响这项设置。

## 构建与验证

成功迁移后以 schema 1 保存旧配置；聚焦回归覆盖小项开关、倍率及含旧总开关／快捷键字段的配置兼容。配置损坏或版本未知时保留原文件并报告错误。

产品源码仅为 `src/Rebuild/`。通过仓库 Author SDK 构建，游戏加载程序集保持 `netstandard2.0`；Native V2 与 Dependency V1 证明由 SDK 生成。只打包产品程序集及产品元数据，原生引用不进入包。

聚焦行为测试：`build/test-unit.ps1 -Focus actionspeed`。独立原生短测探针**不属于发布包**；它使用指定槽位和临时设备，要求 Runtime lock、NoNativeSave 与清理预检。此类探针结果与普通离线单元测试分开，直接调用结果不代表实体持续右键输入已经验证。

## 旧配置升级

首次读取无版本号配置时，保留六类禁用项和倍率，迁移 `ToolSpeedEnabled`、`BottleFillSpeedEnabled`、`EatDrinkSpeedEnabled`、`MachineAddSpeedEnabled`、`HarvestSpeedEnabled`、`PlantSpeedEnabled` 及对应改名倍率。`AutoFillBottle`、`AutoFillStrong`、`ContinuousDrinkWithRightClick` 分别映射到当前同义选项。新旧字段同时出现时以新字段为准。各功能只按各自小项开关执行；整个 Mod 的启用和停用走官方 Mod 路径。

旧 `Profile` 转为实际自动装水间隔：Safe 保留自定义间隔（缺省 0.25 秒），Fast 为 0.18 秒，Debug 为 0.10 秒；强力间隔分别上限为 0.12／0.08／0.08 秒。旧总开关 `Enabled` 和独立快捷键 `MenuKey` 已停用，统一使用 DTMAPI 的模组配置入口。带这两个字段的旧版或 schema 1 配置仍可读取，小项选择保留；旧 `Enabled=false` 不再压住已开启的小项。schema 1 不因废弃字段而在启动时强制改写，下次正常保存时不再输出这两个字段。旧调试标签、详细日志和自定义持续饮水键不再驱动执行；持续饮水跟随原生右键使用输入。新安装仍使用上文默认值。

成功迁移才通过平台原子配置写入器保存；当前格式重开不重复改写。动画恢复逐个处理角色、工具与帽子时钟；setter 失败保留责任，下一次恢复后才应用新倍率，外部后写值保留。
