# 更多装备槽

安装 DTMAPI 0.7.5，启用更多装备槽后进入存档。打开背包，原生装备栏旁会多出三个属性装备槽。

## 放入和取出装备

拿起一件帽子或特殊饰品，点击额外槽放入。空手点击已有装备的额外槽，可以把它退回背包；拿着另一件装备点击，则进行替换。

额外槽增加装备效果，人物外观仍使用游戏自带的帽子栏。护盾数值、药包是否装满、饰品冷却时间会随装备保留。

替换时先退回原装备，再放入新装备：

- 背包有空位：原装备放入背包。
- 背包已满、原装备没有需要保留的实例状态：通过游戏邮件退回。
- 背包已满、原装备带有护盾等状态：不允许替换，提示先腾出一个空位。
- 游戏调用失败：原槽保留。极少数失败可能多出一件装备，以保住物品为先。

## 保存和退出

装备跟着原生存档一起保存。正常保存后重新进入，额外槽里的装备还在；不保存就退出，会回到上次保存时的状态。

停用 Mod 后，已经保存的装备数据仍留在该存档里。即使用原版游戏再保存一次，重新启用后仍可读取。

## 导入 1.0.1 的旧装备

存档还没有额外槽数据、又找到 1.0.1 的旧文件时，会弹出确认窗口，显示旧角色名和装备数量。

1. 点击“确认”，把装备放回三个额外槽。
2. 正常保存游戏。保存成功后，旧文件改名为 .imported 并保留，不删除。
3. 重新进入，直接读取存档中的装备，不再重复导入。

选择“取消”后，可以从装备栏的“导入旧装备”按钮重新打开窗口。采用后不保存就退出，下次仍会询问，旧文件不会改名。导入允许与背包里已有的装备重复。

旧文件按“上次原生保存时额外槽里有什么”读取。没保存的换装不算；旧 Runtime 尝试退回、但尚未保存的装备仍可导入；已经退回并保存的装备不再导入。

## Runtime 仍是 0.7.0 时

更多装备槽更新到 2.0 后，需要手动把 Runtime 更新到 0.7.5。

在更新 Runtime 前，0.7.0 不会加载新版 Mod，而会用旧恢复功能把旧文件中的装备退回背包或邮件：

- 在 0.7.0 下保存过：升级后装备留在背包或邮件，不再弹出导入窗口。
- 在 0.7.0 下没保存就退出：升级后弹出导入窗口，确认后装备回到额外槽。

## 注意

- 存档中的装备数据损坏或来自更新的版本时，额外槽暂时不能使用，并提示原因。原数据不会被空槽覆盖。
- 旧文件读不懂时也会提示原因，文件保持原样。不要为了消除提示而删除旧装备文件。
- 只导入已发布的 1.0.1 文件。不支持更早的 0.3.x 旧文件，也不读取未发布的候选文件格式。
